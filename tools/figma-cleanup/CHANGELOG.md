# 변경 기록 (Sketch Cleanup 플러그인)

버전별 ZIP은 `tools/figma-cleanup-releases/`에 보관됩니다. 최신 코드는 `claude/elegant-brown-wdqb3y` 브랜치.

## v0.4.0 — 2026-11-02
- UI 전면 개편: 다크 모드 + 토스 스타일(큰 둥근 카드, 파란 포인트, 바텀 시트, 하단 고정 버튼)
- 범위: 상단 슬라이딩 토글 탭 / 작업: `전체 선택` 칩 + 칩 선택, 좌우 나열
- 폰트 교체 방식 변경: 저장된 매핑표 대신 **탐색 시 쓰는 폰트를 찾아** 없는 폰트마다 드롭다운(검색)에서 대체 폰트 선택
- `미리보기` → `탐색`, 탐색·적용 중 **진행률 바**(단계 이름, %) + 로딩 스켈레톤
- 수정: 적용 확인이 브라우저 `confirm()`이라 Figma 플러그인에서 동작하지 않을 수 있던 문제 → 화면 안 확인 시트로 교체
- 수정: 폰트 교체 시 원래 굵기에 가장 가까운 스타일 자동 선택, 고르지 않은 없는 폰트가 섞인 텍스트는 건너뜀

## v0.3.0 — 2026-11-02
- 추가: **고정폭 텍스트 줄바꿈 보정** (Sketch 박스 폭이 1px 줄어 `19,800`이 두 줄이 되는 경우)
- 수정: 중복 레이어 단계에서 삭제된 노드의 이름을 읽다 나던 오류(`in get_name: The node with id "…" does not exist`)
- 수정: 숨김 레이어 삭제 시 이미 삭제된 조상 아래 노드를 건너뜀

## v0.2.0 — 2026-11-02
- 추가: Sketch 마스크 모서리 보정, 중복 레이어 점검(숨김→PNG 바이트 비교), 색 빠진 아이콘 후보 목록, 정리 전후 화면 비교, 결과 리포트 내보내기(.md/JSON/복사)
