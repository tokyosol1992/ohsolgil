## 반복 체크리스트 (이 순서로, 호출은 묶어서)

1. **누락 폰트 교체** — `SFPro`→`SF Pro`, `PretendardVariable`(띄어쓰기 없음)·`NotoSansCJKkr`·`AppleSDGothicNeo` 등→`Pretendard Variable`
   - 일부 구간 교체가 실패하면 `t.fontName = {...}`로 노드 단위 교체
   - **장식·스포츠 폰트(`SDPress`·`Giants Inline`·`SDAquaBlue`·`STXingkaiSC` 등)는 교체하지 말 것** (사용자 결정: 그대로 둠)
2. **슬라이스(점선) 삭제** — 마스터 쪽을 지우면 인스턴스는 자동 반영. 삭제는 호출의 맨 마지막에
3. **아이콘·로고 마스터 뒤 배경 fill 제거** — `ic/*`·`check/*`만. `ic/64`·`b2b/profile`·`_/Key`·`btn/*`·날짜·토글·indicator는 배경이 디자인이라 유지
4. **색 빠진 아이콘 복구** — 흰 선/채움이 흰 바탕에서 안 보이는 것(닫기 X, 참여인원 등)을 `#1B1D1F` 또는 `#666`로
   - ⚠️ 어두운 바탕·파란 원 위의 흰 아이콘은 정상. 코치마크는 흰 프레임 위에 딤을 덮는 구조라 "조상 배경 밝기"로 판별하면 오탐
5. **Sketch 마스크 모서리 복구** — 마스크 사각형의 `cornerRadius`가 Figma에서 사라짐 → 마스크 위 프레임/이미지에 `cornerRadius`+`clipsContent` 직접 적용
6. **숨김 레이어 삭제** — 화면에 직접 있는 것만(마스터·인스턴스 내부 제외). 삭제 전 목록을 사용자에게 보여주고 승인받기
7. **중복 레이어** — 숨김→화면 PNG 비교→동일할 때만 삭제 (지금까지 실제 삭제 대상은 거의 없었음)
8. **마스터–화면 색 일치** — 마스터는 `Symbols` 페이지와 화면 페이지의 숨은 `External Symbols` 그룹 **둘 다** 있음. 화면은 External을 씀 → 양쪽에 같이 적용
9. **대표 화면 렌더링 확인** (`get_screenshot`, `enableBase64Response: true`), 결과를 `AGENTS.md`에 기록

## 알게 된 함정

- `hasMissingFont`는 폰트를 `loadFontAsync` 하기 전엔 오탐 → 먼저 로드하고 센다
- 슬라이스를 지운 같은 호출에서 `findAll`로 이름을 읽으면 삭제된 인스턴스 노드 오류 → 순회는 `try/catch`, 삭제는 마지막
- 하단 탭(`btn/navi`)처럼 상태로 색이 갈리는 컴포넌트는 마스터를 바꾸지 말고 인스턴스만 바꾼다
- `use_figma`는 페이지 전환을 호출당 1회만. 여러 페이지는 한 메시지에서 병렬 호출
- 승인 창이 많이 뜨면 호출을 묶는다(자동 모드여도 허용 규칙이 없으면 물어봄). `.claude/settings.json`은 에이전트가 직접 못 고침

## 소통 규칙

- 사용자는 디자이너 → **노드 ID 대신 화면 이름·눈에 보이는 모습**으로 설명
- 삭제·구조 변경은 목록을 먼저 보여주고 승인받기
- 경력·성과 등 내용은 **사용자에게 받은 것만** 사용, 지어내지 않기
