# Sketch Cleanup (Figma 플러그인 뼈대)

Sketch → Figma로 넘어온 파일의 반복 정리 작업을 한 번에 처리합니다. 기본은 **미리보기 → 적용** 순서입니다.

## 불러오기 (로컬 개발)
Figma 데스크톱 → Plugins → Development → **Import plugin from manifest…** → 이 폴더의 `manifest.json` 선택.
(`manifest.json`의 `id`는 임시값입니다. 공개 전에 Figma가 발급한 값으로 바꾸세요.)

## 지금 들어 있는 기능
| 작업 | 설명 |
|---|---|
| 누락 폰트 교체 | 매핑표(기본: NotoSansCJKkr→Pretendard Variable 등, UI에서 수정 가능). 섞인 폰트는 구간별로 원래 폰트·굵기 유지 |
| 슬라이스 삭제 | 점선 슬라이스. 인스턴스 안 것은 건너뜀(마스터에서 지우면 사라짐) |
| 숨김 레이어 삭제 | 컴포넌트는 제외 |
| 아이콘·로고 배경 fill 제거 | 이름이 `ic/`·`icon`·`logo`로 시작하는 컴포넌트의 자체 fill |
| Sketch 마스크 모서리 보정 | 모서리 반경이 있는 `Mask` 사각형(마스크로 동작 안 하는 것)의 바로 위 형제가 같은 영역·반경 0이면 반경 복사 + 프레임은 클리핑. 이미 마스크로 동작하는 것·인스턴스 안은 건드리지 않음 |
| 중복 레이어 점검 | 같은 부모 안에서 종류·위치·크기·채움·선·모서리·텍스트가 모두 같은 형제가 후보. 적용 시 후보를 숨기고 맨 위 프레임 PNG를 숨기기 전과 바이트 비교 → 같을 때만 삭제, 다르면 복구. 그룹·프레임·컴포넌트·인스턴스·마스크는 제외 |
| 색 빠진 아이콘 후보 | 64px 이하 컴포넌트 중 보이는 칠/선이 전부 흰색이거나 하나도 없고, 뒤에 색 배경이 없는 것을 **목록으로만** 보여줌(수정 안 함). 항목을 누르면 Figma에서 선택·확대. 사용처 수를 함께 표시 — 색 원 위에 놓여 정상인 흰 아이콘은 사람이 판단 |
| 고정폭 텍스트 줄바꿈 보정 | 폭·높이 고정(NONE)이고 공백 없는 짧은 텍스트가 폭 부족(예: 49px)으로 두 줄이 된 경우, 필요한 폭(올림)으로 늘림. 오른쪽 정렬은 오른쪽 끝, 가운데 정렬은 중심 고정. 인스턴스 안은 마스터에서 고쳐야 해서 건너뜀 |

## 정리 전후 화면 비교
"적용" 직전에 프레임을 이미지로 저장하고(선택한 최상위 프레임이 있으면 그것, 없으면 범위 안 최상위 프레임 최대 12개, 폭 360px), 적용 후 다시 내보내 **전/후를 나란히** 보여줍니다. 달라진 픽셀 비율도 함께 표시(5% 초과는 빨간색). 폰트 교체는 글자 모양이 바뀌므로 어느 정도 차이가 나는 게 정상이고, **의도하지 않은 큰 변화**를 잡는 용도입니다. 적용 후 문제가 있으면 Figma의 Undo(Cmd/Ctrl+Z)로 되돌릴 수 있어요.

## 리포트 내보내기
미리보기·적용 결과 아래의 **리포트 저장(.md) / JSON 저장 / 복사** 버튼으로 마지막 결과를 내보냅니다(파일 이름, 범위, 작업별 발견·결과·실패, 아이콘 후보 목록, 정리 전후 비교의 달라진 픽셀 비율 포함). 전후 비교는 이미지 계산이 끝난 뒤에 저장해야 리포트에 들어갑니다. 정리 이력을 파일별로 남겨 두는 용도입니다.
